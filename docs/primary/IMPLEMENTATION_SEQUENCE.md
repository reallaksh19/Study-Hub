# Primary implementation sequence

The roadmap is intentionally serialized where semantic drift would otherwise create rework.

```text
#41 Architecture freeze
      ↓
#42 Evidence semantics
      ↓
#43 Minimum contracts
      ↓
#44 Grade 4 fractions: cross-renderer plumbing
      ↓
#45 Teacher Runtime: interpret the real #44 evidence
      ↓
#46 Grade 4 English: inference + source-boundary regression
      ↓
Real-child observation gate
      ↓
#47 IB PYP + NCF-SE/NCERT overlays
      ↓
#48 Grade 5 + future competition seams
```

#39 remains a parallel provider/backend track. Every phase above must remain provider-neutral.

## Gate meanings

- **#41** proves ownership and semantics are unambiguous.
- **#42** proves short-term performance evidence is not mislabeled durable mastery.
- **#43** freezes the smallest cross-app learning contracts only after #42 semantics are stable.
- **#44** proves Study-Hub/print/Kani/return evidence plumbing with one Grade 4 fractions journey.
- **#45** proves adaptive teacher behaviour against the actual #44 journey plus synthetic replay cases.
- **#46** proves English-specific evidence, interpretation and source-rule boundaries.
- **Observation gate** checks whether the learning loop works with a supervised real child before broad scale-up.
- **#47** adds curriculum overlays only after the learning loop survives technical and observational falsification.
- **#48** proves Grade 4→5 vertical progression and adds only dormant competition seams.
