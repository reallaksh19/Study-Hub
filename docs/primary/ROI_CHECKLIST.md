## High ROI — must affect roadmap/contracts

- [x] Evidence vs Teacher Runtime ownership split
- [x] Multidimensional learning evidence instead of one mastery state
- [x] #42 must precede #43

## Medium ROI — adopt without over-expanding architecture

- [x] Representation role: provided / child-selected / child-produced
- [x] Bounded learner agency teacher moves
- [x] Compact feedback/teacher-voice policy
- [x] QR attempt-not-score / activity-not-mastery / return-required semantics

## Justification rule

An item is High ROI when it prevents semantic duplication, expensive contract rework, or directly addresses the original failure mode of a tutor repeatedly answering without understanding why the child is stuck.

An item is Medium ROI when it materially improves evidence quality or learner experience but can be added without blocking the core architecture.
